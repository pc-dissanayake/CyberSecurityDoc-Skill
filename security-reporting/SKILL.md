# Security Reporting

Translate technical findings into structured, prioritized, understandable reporting.

## Required output patterns

- executive summary
- technical findings
- severity rationale
- impact description
- remediation guidance
- verification method

## Report best practices

- separate confirmed risks from suspected ones
- justify severity with exploitability and business impact
- include evidence and clear remediation ownership
- provide a prioritized roadmap rather than a generic list
