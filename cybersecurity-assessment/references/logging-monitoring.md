# Logging and Monitoring

## Review areas

- security event logging
- authentication and authorization auditing
- admin action logging
- log integrity and retention
- alerting and detection coverage
- centralization and tamper resistance
- incident response readiness

## Assessment questions

- Are security-relevant actions recorded?
- Are logs sufficient to support forensic investigation?
- Are alerts actionable and tested?
- Is there enough context to differentiate legitimate and malicious actions?

## Example findings

- silent failures in sensitive actions
- missing audit trails for configuration changes
- logs that do not capture user identity or source context
- insecure or non-centralized log storage
