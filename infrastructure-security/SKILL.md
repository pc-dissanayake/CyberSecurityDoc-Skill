# Infrastructure Security

Review infrastructure as a set of attack surfaces and privilege boundaries.

## Review checklist

- port exposure and network segmentation
- host hardening and patch posture
- admin access controls
- service identity and least privilege
- secrets and configuration handling
- TLS and certificate posture
- logging and monitoring
- backup and recovery controls

## Assessment approach

Favor passive review, configuration analysis, and controlled validation. Avoid destructive or high-impact network tests without explicit scope and approval.
